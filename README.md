# Personal Portfolio (haidangtrih.me)

Source repository for my personal portfolio website, presenting technical work, engineering case studies, education, and recognition.

**Live Website:** [haidangtrih.me](https://haidangtrih.me)

## Tech Stack

- **Framework:** Next.js 16 (App Router) with React 19 and TypeScript
- **Styling:** Vanilla CSS modules with design tokens
- **Animations:** GSAP (`useGSAP` hook) with ScrollTrigger and Framer Motion
- **Icons & Typography:** Lucide React, Geist sans/mono fonts

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view locally.

## Project Structure

- `src/app/`: Next.js App Router pages and case studies (`/projects/deepflood`, `/contact`, etc.)
- `src/components/`: Modular UI components (Hero, Experience, Projects, LineSidebar)
- `public/`: Static assets and icons
